维度详情

本引擎默认由本地规则计算驱动（维度关键词 + 情感词表），零 API 调用、可复算、结论可溯源到真实评论；在右上角「⚙ 设置」中启用云端大模型（豆包 / 火山方舟）后，评论识别与图像识别可调用大模型以增强理解（按 token 计费）。
维度体系以郭之昊等(2026)《农业工程学报》葡萄电商评论标注方案为依据 · 改进建议来自农产品改进知识库与冷链/分级国标。

⚙ 设置 · 大模型 API 配置（豆包 / 火山方舟）
在火山方舟控制台「API Key 管理」创建。密钥只存在你浏览器本地，调用时仅发往 127.0.0.1 本地代理与方舟官方接口，我们服务器不留存。
若你上网必须开代理（如宿舍/校园网、或装了 Clash/梯子软件），请在此粘贴代理地址。软件里的本地服务器会经由它访问火山方舟。留空时也会尝试自动读取 Windows 系统代理。
未启用或未填 Key 时，软件照常用本地规则引擎（零成本、可复算）。启用后评论识别与图像识别将调用云端大模型，按 token 计费（见软件说明 / 下方对话）。
